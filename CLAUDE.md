## Проверка тикета в статусе `review`
1. `git log` / `git diff` по тикету, `STATUS.md`.
2. Соответствие контрактам: схемы, AI-слой (§6), модель данных (§4), правило оценки (§5).
3. Ключ API не утекает (код, логи, URL, резервная копия, коммиты); в
   коммитах нет личных фраз; модели не захардкожены вне `defaults.ts`;
   тексты в `ru.ts`.
4. Тесты проверяют поведение, а не только «рендерится».
5. Нет лишнего сверх тикета.
6. `npm run lint && npm test && npm run build`.
7. Итог: `done` или список замечаний в `STATUS.md` → «Замечания по ревью»,
   тикет обратно в `in progress`.
