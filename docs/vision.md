# Wortwechsel — видение продукта

> Владелец документа: Claude (архитектор). Меняет только Claude или Лена.

## Проблема

Немецкий у Лены на уровне B2. Грамматика в целом держится, но в живой речи
она по привычке берёт самые простые слова: `machen`, `sagen`, `gehen`,
`gut`, `Sache`. Пассивно она знает больше, но в разговоре эти слова не
«достаются». Карточки «слово → перевод» (Quizlet) тренируют узнавание,
а не использование.

## Идея

Приложение работает с **её собственной речью**, а не с чужими списками слов.

```
Говорю фразу  →  AI предлагает 1–3 точные замены  →  сохраняю нужные
      ↑                                                        │
      └──  через 1–7–30 дней: «скажи эту же фразу без machen»  ┘
```

Главный механизм — **повторение собственных фраз**: через несколько дней
приложение показывает её старое предложение и просит сказать его вслух
иначе, без слабого слова. AI проверяет ответ. Слово считается выученным,
когда она несколько раз **сама употребила** его правильно.

## Принципы

1. **Связки, а не синонимы.** Учим `einen Termin vereinbaren`, а не
   «machen = vereinbaren». Каждая замена привязана к её предложению.
2. **Меньше, но точно.** Максимум 3 замены на фразу. Если простое слово —
   самое естественное, AI говорит «оставь как есть».
3. **Живая речь, а не C1-словарь.** У каждой замены есть пометка стиля:
   разговорное / нейтральное / официальное. Книжные слова, которые в
   разговоре звучат странно, не предлагаются.
4. **Голос в обе стороны.** Фразу говорят вслух, ответ на повторении тоже
   вслух. Текст можно поправить, если распознавание ошиблось.
5. **Телефон — главное устройство.** Говорить удобно в дороге, а не за ПК.
6. **Прогресс = изменение речи.** Метрика — сколько выражений перешло в
   активный словарь и как реже стали слабые слова, а не «выучено 500 карточек».

## Что входит в первую версию (MVP, фаза 1)

- Записать фразу голосом (или ответить на вопрос-подсказку).
- Распознать текст, дать его поправить.
- Анализ: 0–3 замены с объяснением на русском, исправление грамматики,
  улучшенная фраза, озвучка улучшенной фразы.
- Сохранить выбранные замены.
- Повторение по расписанию (FSRS): «скажи иначе» голосом + оценка AI.
- Список «Мои выражения», настройки, экспорт/импорт резервной копии.
- Установка на телефон как приложение (PWA).

## Что сознательно НЕ входит в MVP

| Не делаем сейчас | Почему |
|---|---|
| Синхронизация с Quizlet | Публичного API нет. Экспорт в TSV — фаза 2. |
| Диалоговый тренер | Отдельный продукт. Фаза 3. |
| Синхронизация телефон ↔ ПК | Сложно. В v1 — экспорт/импорт файла. |
| Аккаунты, несколько пользователей | Приложение для одного человека. |
| Хранение аудио | Не нужно для обучения, занимает место. |

## Фазы

- **Фаза 0 — проверка идеи (без кода приложения).** Прогнать 15–20 своих
  реальных фраз через промпт анализа. Если подсказки слабые — сначала
  чинится промпт, а не пишется приложение.
- **Фаза 1 — MVP.** Тикеты T01–T08.
- **Фаза 2 — глубже.** Задания «своё предложение с новым словом»,
  статистика слабых слов, экспорт для Quizlet/Anki, счётчик расходов.
- **Фаза 3 — диалоговый тренер.**

## Критерий успеха

Через 2 месяца регулярного использования:
- ≥ 40 выражений в статусе «активное»;
- частота слов из списка «слабых» в новых фразах заметно ниже, чем в первые
  две недели (будет видно в статистике фазы 2 — данные копятся с первого дня).
