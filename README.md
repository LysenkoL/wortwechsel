# Wortwechsel

Приложение для тренировки **активного** словаря немецкого по собственной
речи: говоришь фразу → получаешь 1–3 точные замены простых слов →
через несколько дней снова говоришь ту же фразу, но уже с новыми словами.

> *Wortwechsel* — «обмен словами», «перепалка». Здесь буквально:
> меняем слова на более точные.

Работает бесплатно: приложение на GitHub Pages, анализ — Gemini API на
бесплатном тарифе (ключ хранится только на телефоне), распознавание речи —
средствами браузера.

## С чего начать

| Ты… | Читай |
|---|---|
| Лена, хочешь понять план | `docs/vision.md` → `docs/workflow.md` → `tasks/README.md` |
| Агент-исполнитель (Codex, GPT, Cursor) | `AGENTS.md` → `STATUS.md` → свой тикет |
| Claude | `CLAUDE.md` → `STATUS.md` |

## Что где лежит

```
AGENTS.md        правила для всех агентов
CLAUDE.md        роль архитектора и чек-лист проверки
STATUS.md        где остановились — читать первым
docs/
  vision.md        что строим и что нет
  architecture.md  стек, данные, API, повторение
  decisions.md     почему так решили
  workflow.md      как работать вдвоём: Claude + GPT
tasks/           доска и тикеты T00–T08
prompts/         промпты анализа и проверки (ядро продукта)
schemas/         JSON-схемы ответов AI
data/            вопросы-подсказки
validation/      фаза 0: свои фразы и чек-лист оценки
```

## Как работаем

Сначала всё делается и проверяется **локально** (ПК и телефон через
домашний Wi-Fi). В интернет — только когда приложение доведено до ума
и Лена скажет «публикуем».

## Текущий этап

Фаза 0 — проверка, что подсказки полезны. Подробно:
`validation/checklist.md`.

## Запуск у себя

Двойной клик по `start.bat` (нужен Node.js) — сам поставит пакеты и откроет приложение.

## Публикация

1. Репозиторий `wortwechsel` на GitHub — **публичный** (бесплатные Pages только для публичных).
2. Settings → Pages → Source: **GitHub Actions**.
3. `git push` в ветку `main` — Actions соберёт и выложит. Адрес: `https://<логин>.github.io/wortwechsel/`.
4. В Google Cloud Console ограничь ключ сайтом `https://<логин>.github.io/*`.
5. На телефоне открой адрес в Chrome → меню → «Установить приложение».

## Команды

Появятся после T00/T01: `npm run validate`, `npm run dev`, `npm test`,
`npm run build`.
