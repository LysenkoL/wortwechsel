# Фаза 0 — проверка: полезны ли подсказки?

Цель: за один-два вечера понять, даёт ли анализ замены, которые ты
**реально стала бы учить**. Если нет — сначала чиним промпт, а не пишем
приложение.

## 1. Получить бесплатный ключ Gemini API (5 минут, без карты)

1. Открыть Google AI Studio (aistudio.google.com) и войти Google-аккаунтом.
2. «Get API key» → «Create API key» → скопировать.
3. Положить ключ в файл `.env.local` в корне проекта:
   ```
   GEMINI_API_KEY=ваш_ключ
   GEMINI_MODEL=имя модели Flash-Lite из списка в AI Studio
   ```
   Этот файл не попадает в GitHub. Никому ключ не отправляй — и мне в чат тоже.
4. В AI Studio видно, сколько бесплатных запросов в день даёт каждая модель.
   По отзывам разработчиков: у Flash — около 20 в день, у Flash-Lite —
   в разы больше. Лимит обновляется около 9:00 утра.

Важно: на бесплатном тарифе Google может использовать тексты запросов
для улучшения своих продуктов. Не вписывай в фразы имена, адреса,
данные о здоровье — замени на нейтральные.

## 2. Собрать фразы (15–20 штук)

- Бери **свои настоящие** фразы: что говорила сегодня на работе, в
  магазине, по телефону, что писала коллегам. Можно наговорить в
  диктофон и переписать **как есть, с ошибками** — не исправляй.
- Смесь контекстов: ~7 работа, ~7 быт, ~4 учреждения.
- Разной длины: и короткие, и длинные с «weil», «dass».
- Впиши в `validation/phrases.txt` по одной на строку (пример формата —
  в `validation/phrases.example.txt`):
  ```
  work | Ich muss das heute noch machen, weil der Kunde wartet.
  daily | Am Wochenende sind wir in den Zoo gegangen.
  office | Ich brauche einen Termin, weil mein Ausweis ist abgelaufen.
  ```

## 3. Прогнать

**Вариант A — скрипт (тикет T00):**
`npm install`, затем `npm run validate` → появится `validation/report.md`.
Сравнить две модели: сначала все фразы на Flash-Lite, потом 10 фраз на
Flash (`npm run validate -- --model=<имя Flash> --limit=10`). Если Flash
заметно лучше — анализ будет на нём, а проверка ответов на Flash-Lite.

**Вариант B — без кода, в Google AI Studio (бесплатно):**
1. Create prompt → в «System instructions» вставить весь текст
   `prompts/analyze.md`.
2. Включить «Structured output» и вставить схему из
   `schemas/analyze.schema.json`.
3. Отправлять фразы по одной в виде `{"transcript": "…", "context": "work"}`.

**Вариант C — в ChatGPT (твоя подписка Plus):** вставить текст
`prompts/analyze.md`, добавить «Отвечай только JSON» и отправлять фразы
по одной. Годится, чтобы оценить сам промпт, но в приложении будет
работать Gemini — поэтому лучше A или B.

## 4. Оценить каждую замену

| Отметка | Значит |
|---|---|
| ✅ | Взяла бы и учила. Точно, естественно, мне пригодится. |
| 🤔 | Не уверена: может, и так, но сама бы не выбрала. |
| ❌ | Странно, книжно, меняет смысл или неправильно. |

Отдельно отметь:
- фразы, где замен **не хватило** (ты чувствуешь, что можно лучше);
- фразы, где модель **исправила то, что было правильно**.

## 5. Решение

| Результат | Что дальше |
|---|---|
| ✅ ≥ 70% и ❌ ≤ 10% | Промпт годится → фаза 1 (T01 и дальше). |
| ✅ 50–70% | Принеси отчёт Claude → правка промпта → повторный прогон. |
| ✅ < 50% | Принеси отчёт Claude → разбираемся: промпт, модель или сама идея. |

В любом случае покажи отчёт Claude: он проверит немецкий в примерах
(модель могла ошибиться так, что на глаз не заметно).
