# Правила для агентов (Codex / GPT / Cursor / Claude Code)

Проект: **Wortwechsel** — PWA для тренировки активного словаря немецкого
по собственной речи. Что и зачем — `docs/vision.md`.

## Роли

| Кто | Роль |
|---|---|
| **Лена** | Владелец продукта. Решает, что делаем; тестирует на телефоне. |
| **Claude** | Архитектор и оркестратор. Пишет архитектуру, промпты, схемы, тикеты; проверяет готовые тикеты. Может и реализовывать. |
| **GPT / Codex** (и любой другой агент) | Исполнитель. Реализует тикеты строго по спецификации. |

## Главное правило: сначала локально, до идеала
- Всё разрабатывается и проверяется **только локально** на компьютере Лены
  (папка `C:\Users\elenk\wortwechsel`, `npm run dev`, телефон — через
  домашний Wi-Fi `npm run dev:phone`).
- **Ничего не выкладывать в интернет**: не создавать удалённый репозиторий,
  не делать `git push`, не настраивать GitHub Pages и Actions, не
  предлагать публикацию по ходу работы.
- Публикация — только тикет T08 и только после того, как Лена прямо
  написала «готово, публикуем». До этого T08 не начинать.

## Перед началом работы — всегда
1. Прочитай `STATUS.md` — где остановились и что следующее.
2. Прочитай `tasks/README.md` и **один** тикет, который берёшь.
3. Прочитай разделы `docs/architecture.md`, на которые ссылается тикет.
4. Поставь тикету в `tasks/README.md` статус `in progress` и своё имя.

## Защищённые файлы — исполнитель НЕ меняет
- `docs/vision.md`, `docs/architecture.md`, `docs/decisions.md`
- `prompts/*`, `schemas/*`
- тексты тикетов `tasks/T*.md` (статусы в `tasks/README.md` менять можно)

**Сгенерированные файлы** (`*.generated.ts`) не правятся руками никем —
только через `npm run sync`.

## Если спецификация неясна или мешает
- Неясно, но контракты не затрагиваются → выбери самый простой вариант,
  который не противоречит `docs/architecture.md`, и запиши его в
  `STATUS.md` → «Принятые мелкие решения».
- Нужно менять контракт (схему, API, модель данных, промпт) → **остановись**
  и запиши вопрос в `STATUS.md` → «Вопросы к Claude».
- Только если Лена явно сказала продолжать без Claude: внеси минимальное
  изменение и добавь запись в конец `docs/decisions.md` с пометкой
  **ПРЕДЛОЖЕНО (GPT)** — Claude проверит позже.

## Правила кода
- TypeScript `strict`, без `any` (кроме границ с внешними API, с комментарием).
- Типы ответов AI — только из `contracts.generated.ts`.
- Тексты интерфейса — только в `src/i18n/ru.ts`.
- База данных — только через `src/db/repo.ts`.
- Сеть — только через `src/ai/` (своего сервера нет; в конце приложение
  будет статическим сайтом на GitHub Pages).
- Ключ API вводит пользователь в настройках, он хранится только в
  IndexedDB. Никогда не в коде, не в репозитории, не в логах, не в URL,
  не в резервной копии.
- Репозиторий позже станет публичным: уже сейчас никаких личных данных в
  коммитах (`validation/phrases.txt`, отчёты, `.env*` — в `.gitignore`).
- Названия моделей — только из настроек и `src/ai/defaults.ts`.
- Логика (`src/srs`, `src/db`, `src/ai`) покрыта тестами.
- Вёрстка сначала под телефон (360–430 px), кнопки ≥ 48 px.
- Идентификаторы и комментарии в коде — по-английски. Общение с Леной и
  документы — по-русски.
- Не добавляй функции, которых нет в тикете. Идея — в `STATUS.md` →
  «Идеи на потом».

## Тикет готов, когда
1. Выполнен раздел «Готово, когда» тикета.
2. `npm run lint && npm test && npm run build` — без ошибок
   (до появления этих скриптов — то, что требует тикет).
3. Сделан коммит: `T03: краткое описание`.
4. Тикет в `tasks/README.md` → `review`.
5. Обновлён `STATUS.md` (см. ниже).

## Передача смены — обязательно
В конце каждой сессии, **а также когда чувствуешь, что контекст или лимиты
заканчиваются**, обнови блок «Передача смены» в `STATUS.md`:
что сделано, что осталось, как проверить, на чём остановился (файл/функция),
открытые вопросы. Следующий агент начинает только с этого блока —
пиши так, чтобы его хватило.

## Git (только локально)
- Локальный репозиторий без удалённого (`git init` уже/ещё нужно сделать —
  см. `STATUS.md`). `git push` не делать до T08.
- Коммит после каждого законченного шага, не реже одного на тикет.
- Claude не может запускать git и npm на компьютере Лены: если в папке
  есть незакоммиченные изменения от Claude — проверь их (`npm test`) и
  закоммить с пометкой `(Claude)` в сообщении.
- `.env.local` никогда не коммитится.
- Не переписывай историю.
