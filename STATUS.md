## Принятые мелкие решения
- Слияние при импорте: у выражения побеждает запись с большим
  `max(createdAt, card.last_review)`.
- Модели по умолчанию — алиасы `-latest` (`src/ai/defaults.ts`), меняются в Настройках.
- Тексты интерфейса — группами `ruX` в `src/i18n/ru.ts`.
- Резервная копия не содержит настроек и ключа API.
- T00: вместо `node --env-file` — свой загрузчик `.env.local`
  (`scripts/lib/env.mjs`): работает на любом Node ≥ 20 и не падает,
  если файла нет. Переменная `GEMINI_BASE_URL` — только для тестов.
