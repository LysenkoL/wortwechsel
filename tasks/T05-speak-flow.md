# T05 — Экран «Говорить»: фраза → анализ → сохранение

**Зависит от:** T02, T03, T04 · **Размер:** L · **Делает:** любой агент

## Экран (`src/routes/SpeakPage.tsx` + `src/features/speak/`)
Сверху вниз:
1. **Контекст** — 4 «чипа»: Работа · Быт · Учреждения · Свободно
   (`work`, `daily`, `office`, `free`). Выбор запоминается в
   `settings.lastContext`.
2. **Вопрос-подсказка** (если контекст не `free`): случайный вопрос из
   `data/questions.json` для контекста + кнопка «Другой вопрос».
   Переключатель «Без вопроса».
3. **Речь** — `RecordButton` (T04). После «Стоп» распознанный текст
   переходит в поле на шаге 4. Ссылка «Ввести текстом» открывает поле
   сразу (удобно на ПК). Мелкая подпись: «Не называй имён, адресов и
   данных о здоровье — фраза уходит в Google.»
4. **Текст** — редактируемое поле с подписью «Проверь: так ли ты
   сказала? Исправь, если распознавание ошиблось.» Кнопка «Анализировать»
   → `ai.analyze({ transcript, context })`.
5. **Результат** (`AnalysisView`):
   - `is_german: false` → «Не получилось распознать немецкую фразу. Попробуй ещё раз.»
   - блок «Грамматика», если `corrected_sentence` не пустая: исправленная
     фраза и `grammar_notes`;
   - карточки `suggestions`: крупно `original → replacement`, ниже
     `lemma` · `pattern`, `meaning_ru`, `note_ru`, бейдж стиля
     (разг. / нейтр. / офиц.), пример курсивом; чекбокс «Учить»
     (по умолчанию включён);
   - `keep` — серым: «Можно оставить: gehe — …»;
   - «Как сказать лучше»: `improved_sentence` + кнопка 🔊
     (`speechSynthesis`, `lang: 'de-DE'`, голос и скорость из настроек,
     по умолчанию 0.95);
   - пусто в `suggestions` → «Хорошая фраза — заменять нечего.»
6. Кнопка **«Сохранить (N)»** → `repo.saveUtterance(...)` (с `rawTranscript`
   из распознавания и итоговым `transcript`) → «Сохранено: N. Первое
   повторение — завтра.» → экран сбрасывается к шагу 3, контекст остаётся.

## Состояния и ошибки (`AiError.code` → текст из `ru.ts`)
- Во время запроса — индикатор, кнопки неактивны.
- `NO_KEY` → «Сначала введи ключ Gemini API в Настройках» + ссылка.
- `BAD_KEY` → «Ключ не подходит. Проверь его в Настройках.»
- `QUOTA` → «Бесплатный лимит на сегодня исчерпан. Он обновится около 9:00 утра.»
- `BLOCKED` → «Модель отказалась отвечать на эту фразу. Попробуй переформулировать.»
- `NETWORK`, `TIMEOUT`, `BAD_RESPONSE` → «Не получилось получить ответ.
  Попробуй ещё раз.» + кнопка «Повторить» (текст не теряется).
- Все тексты — в `ru.ts`.

## Тесты
`AnalysisView` на фикстурах — трёх примерах выхода из `prompts/analyze.md`
(скопировать в `src/features/speak/__fixtures__/`): отрисовка, снятие
чекбокса меняет N, пустые suggestions → нужный текст, пустой
`corrected_sentence` → блока «Грамматика» нет. Экран с замоканным
`ai.analyze`: каждый код ошибки → свой текст.

## Готово, когда
`npm run dev` с ключом в настройках: речь → текст → анализ → сохранение
→ запись видна в IndexedDB (DevTools → Application). Вёрстка проверена
на 360 px. `STATUS.md` обновлён.
