# T08 — Публикация на GitHub Pages и установка на телефон

**Зависит от:** T06, T07 **и слово Лены «готово, публикуем»** · **Размер:** S · **Делают:** агент + Лена

> Не начинать, пока Лена прямо не написала, что приложение доведено до ума
> локально и его можно выкладывать. До этого — никакого GitHub и Pages.

## Агент
- `.github/workflows/deploy.yml`: при push в `main` — `npm ci`,
  `npm test`, `npm run build` (с `sync` через `prebuild`), публикация
  `dist/` на GitHub Pages официальными actions (`actions/upload-pages-artifact`,
  `actions/deploy-pages`); версии actions — актуальные.
- Проверить, что сборка работает с `base: '/wortwechsel/'`: иконки,
  manifest и service worker грузятся по путям с префиксом.
- Перед первой публикацией: `git ls-files` не содержит `.env*`,
  `validation/phrases.txt`, `validation/report.*`.
- `README.md`: раздел «Публикация» — пошагово для Лены, с точными
  названиями кнопок GitHub и Google AI Studio на момент выполнения.

## Лена (по инструкции из README)
1. Публичный репозиторий `wortwechsel` на GitHub, push.
2. Settings → Pages → Source: **GitHub Actions**.
3. Дождаться зелёного запуска в Actions; адрес будет
   `https://<логин>.github.io/wortwechsel/`.
4. В Google Cloud Console у ключа для приложения: ограничение по сайту
   `https://<логин>.github.io/*` и по API — Generative Language API.
5. Открыть адрес на телефоне → установить:
   iPhone — «Поделиться» → «На экран „Домой“»;
   Android — меню Chrome → «Установить приложение».
6. В приложении: Настройки → ключ → «Проверить».

## Проверка на телефоне (чек-лист)
- [ ] Микрофон разрешается, немецкая фраза распознаётся во время речи.
- [ ] Распознавание работает **в установленном приложении**, а не только
      во вкладке браузера (на iPhone — главный риск, D-017). Если нет —
      записать в `STATUS.md`, Claude решит, что делать.
- [ ] Анализ, сохранение, озвучка немецким голосом.
- [ ] `?debug=1` → «Всё доступно сейчас» → повторение голосом проходит.
- [ ] Без интернета: приложение открывается, «Выражения» видны, при
      анализе — понятная ошибка.
- [ ] Резервная копия скачивается, ключа в ней нет.

## Готово, когда
Чек-лист пройден на телефоне Лены; адрес приложения записан в `STATUS.md`.
