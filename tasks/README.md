# Доска задач

Статусы: `todo` · `in progress` · `review` (ждёт проверки Claude) · `done` · `blocked`.
Агент, взявший тикет, ставит `in progress` и своё имя; по готовности — `review`.
Claude после проверки ставит `done` или возвращает с замечаниями.
