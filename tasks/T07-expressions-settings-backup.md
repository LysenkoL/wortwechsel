# T07 — «Выражения», «Настройки», резервная копия

**Зависит от:** T05 · **Размер:** M · **Делает:** любой агент

## «Выражения»
- Вкладки: **Учу** (`learning`) · **Активные** (`active`) · **Пауза** (`suspended`)
  с количеством.
- Поиск по `lemma`, `replacement`, `meaning_ru`.
- Карточка: `lemma` крупно, `pattern`, `meaning_ru`, бейдж стиля;
  «Из фразы: …» (её исходная фраза, `original` подсвечен);
  прогресс «Употребила: 2 из 3 дней»; «Следующее повторение: через 3 дня»
  (относительная дата по-русски, `Intl.RelativeTimeFormat`).
- Действия: «Пауза» / «Вернуть», «Удалить» (с подтверждением).

## «Настройки»
- **Ключ Gemini API** (поле-пароль, кнопка «Показать»), сохраняется в
  `settings.apiKey`. Кнопка «Проверить» — пробный `analyze` на фразе
  «Ich mache das morgen.»; успех → «Ключ работает». Под полем ссылка
  «Как получить ключ» → короткая инструкция (Google AI Studio → Get API key;
  ограничить ключ сайтом `<логин>.github.io` и Generative Language API).
- **Модели**: два текстовых поля «Анализ фраз» и «Проверка ответов» с
  подсказкой-значением из `src/ai/defaults.ts` и кнопкой «По умолчанию».
- **Повторений в день**: 10 / 20 / 30 / 50 (по умолчанию 20).
- **Голос озвучки**: список `speechSynthesis.getVoices()` с `lang`
  `de-*`; скорость 0.8–1.1; кнопка «Послушать».
- **Резервная копия**:
  - «Скачать копию» → `wortwechsel-backup-YYYY-MM-DD.json`; дата
    последнего экспорта → `settings.lastExportAt`. **Ключ API в копию
    не попадает** (в `ExportFile` нет настроек);
  - «Восстановить из файла» → выбор «Заменить всё» / «Объединить»,
    подтверждение, отчёт «Импортировано: N фраз, M выражений».
- **Использование**: «Сегодня: анализ N, проверка M» и то же за месяц.
  Подпись: «Точные бесплатные лимиты видны в Google AI Studio.»
- **Отладка** (видна только при `?debug=1` в адресе перед `#`,
  например `…/wortwechsel/?debug=1#/settings`): «Сделать всё доступным
  сейчас» → `repo.makeAllDueNow()`.

## Напоминание о копии
Если `lastExportAt` старше 7 дней (или не было) и в базе есть хотя бы
5 выражений — на экране «Говорить» плашка «Давно не было резервной копии»
со ссылкой в настройки; закрывается крестиком до следующего дня.

## Тесты
Экспорт → импорт «Заменить всё» → те же данные; «Объединить» не создаёт
дублей; в файле экспорта нет `apiKey`; плашка появляется и не появляется
по условиям.
