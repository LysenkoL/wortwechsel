# T06 — Экран «Повторить»

**Зависит от:** T05 · **Размер:** L · **Делает:** любой агент
**Источник правды:** `docs/architecture.md` §5, D-006, D-007.

## Входит

### Бейдж
На вкладке «Повторить» — число `countDue(now)` (через `useLiveQuery`),
не больше остатка дневного лимита.

### Старт
- Нет заданий → «На сегодня всё. Следующее повторение: <дата>.»
- Есть → «Сегодня: N выражений в M фразах» + «Начать».
- Сессия = `getDueGroups(now, limit − reviewedTodayCount(now))`.

### Задание (одна группа = одна фраза)
1. Метка контекста и счётчик «2 / 5».
2. Фраза Лены (`utterance.transcript`), в ней **подсвечены** `original`
   каждого item группы (поиск без учёта регистра; не нашлось — без
   подсветки, см. architecture §8).
3. Задание: «Скажи эту фразу иначе — без: **gesagt**, **das anders machen**».
4. Подсказка (необязательно), по шагам:
   - 1-е нажатие: `meaning_ru` каждой цели;
   - 2-е нажатие: первые 3 буквы `replacement` + «…».
   Любое нажатие → `hintUsed = true` (оценка не выше Hard).
5. Ответ: `RecordButton` (T04) → редактируемый текст; или
   «Ввести текстом». Кнопка «Проверить».
6. `ai.evaluate({ kind: 'rephrase', sentence, targets, answer, topic: null })`,
   где `targets` — **только** items этой группы (id = `item.id`).
   Ошибки — те же тексты, что в T05. При `QUOTA` сессия
   останавливается: «Лимит проверок на сегодня исчерпан, продолжим завтра.»
   Неоценённые группы остаются на завтра.

### Результат
- По каждой цели: ✓ / ✗, `replacement` и `comment_ru`.
- `errors` списком: «fragment → correction — explanation_ru».
- «Лучше так»: `better_version` + 🔊.
- `feedback_ru`.
- Если все цели получили бы Good — кнопка «Было легко» (переключатель).
- «Дальше» → `repo.applyReview(...)` → следующая группа.
- «Пропустить» на любом шаге до проверки — группа не оценивается,
  остаётся на сегодня.

### Финал
«Готово: повторено N выражений. Стали активными: K.» (K — сколько items
перешли в `active` в этой сессии) + кнопка «На главную».

## Тесты
- Подсветка: точное совпадение, другой регистр, не найдено.
- Сценарий на фикстуре примера 2 из `prompts/evaluate.md`
  (`targets` с подменёнными id): t1 → Again, t2 → Hard, записан `Review`.
- Подсказка ограничивает оценку до Hard.

## Готово, когда
Полный цикл на ПК: сохранить фразу → «Отладка: всё доступно сейчас»
(T07; до T07 — `repo.makeAllDueNow()` из консоли) → пройти повторение →
`due` сдвинулся, `Review` записан. `STATUS.md` обновлён.
