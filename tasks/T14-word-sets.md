# T14 — «Слова»: наборы по темам и тренировки как в Quizlet

## Что появляется
Пятая вкладка **«Слова»** — отдельный модуль рядом с «Говорить/Повторить».
Ядро продукта (своя речь → замены) не меняется; выражения из своей речи можно
перенести в набор.

### 1. Наборы (деки) и темы
- Набор: название, эмодзи, **тема** (те же контексты: Работа · Быт ·
  Учреждения · Свободно), описание.
- Экран «Слова»: фильтр по теме, наборы сгруппированы по темам, у каждого —
  число карточек и полоска прогресса (не изучено / учу / знаю).
- Создать, переименовать, удалить набор.
- **Готовые наборы** (`data/starter-decks.json`, без AI): 4 темы по 12 связок
  уровня B2 — добавляются одной кнопкой.

### 2. Карточки
- Поля: термин (нем.), перевод (рус.), пример (нем.), заметка, ★ «избранное».
- Добавить по одной, править, удалить, озвучить.
- **Импорт списком** (как в Quizlet): строки `термин<TAB>перевод<TAB>пример`
  или через ` - `, ` — `, ` = `, `;`. Строка без разделителя — только термин.
- **Из моих выражений**: выбрать сохранённые выражения → карточки
  (лемма, перевод, пример, связка в заметке).
- **AI** (Gemini, модель анализа, счётчик «генерация»):
  - «Слова на тему…» — N карточек по теме набора (без повторов);
  - «Дополнить» — для карточек без перевода/примера.

### 3. Режимы тренировки
| Режим | Что делает | Пишет в статистику |
|---|---|---|
| Карточки | переворот, «Знаю / Ещё учу», перемешать, озвучка; незнакомые — повторный круг | да |
| Заучивание | раунды по 7: сначала выбор из 4, потом написать; ошибка — карточка вернётся в раунде | да |
| Письмо | перевод → написать по-немецки; проверка с допуском (регистр, ß/ss, ä/ae, 1 опечатка); отдельно «артикль»; кнопка «Я была права» | да |
| Аудирование | слово звучит (TTS) → написать | да |
| Говорение | перевод → сказать по-немецки (Web Speech) → локальная проверка | да |
| Тест | 10/20/все вопросов: выбор, письмо, верно/неверно; итог в % и список ошибок | да |
| Подбор | 6 пар на время, штраф 1 с за ошибку, рекорд набора | нет |
| Повторение | интервальное (FSRS) по всем наборам или по одному: самооценка Снова/Трудно/Хорошо/Легко; новых в день — из настроек | да + FSRS |

Направление вопросов (рус → нем по умолчанию, или нем → рус) и «только ★» —
переключатели на экране набора.
